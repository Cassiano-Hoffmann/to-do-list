# 📝 To-Do List

Uma aplicação simples de lista de tarefas desenvolvida com **HTML5**, **CSS3** e **JavaScript**, com layout **responsivo** para se adaptar a diferentes tamanhos de tela.

## 🔍 Visão Geral

Este projeto tem como objetivo ajudar os usuários a:

- Adicionar tarefas
- Marcar tarefas como concluídas
- Remover tarefas da lista

Tudo isso com uma interface amigável e adaptável para **dispositivos móveis**, **tablets** e **desktops**.

## 📱 Responsividade

O layout foi construído com foco em responsividade, utilizando **media queries** e técnicas modernas de CSS para garantir uma boa experiência em qualquer dispositivo.

## 🛠️ Tecnologias Utilizadas

- **HTML5** – estrutura da aplicação
- **CSS3** – estilização e responsividade
- **JavaScript (Vanilla JS)** – lógica da aplicação
